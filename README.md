# IntensivaHub 🫁⚡

Repositório público de educação médica, protocolos, resumos e atualização contínua em medicina intensiva.

## Objetivo

Organizar conteúdos de medicina intensiva, clínica médica, emergência e educação em saúde para consulta rápida, estudo contínuo e apoio à formação médica.

## Áreas principais

- Protocolos de UTI
- Ventilação mecânica
- Sepse e choque séptico
- Hemodinâmica
- POCUS
- Sedação, analgesia e delirium
- Terapia renal substitutiva
- Neurointensiva
- TEMI
- Educação médica para comunidade

## Aviso importante

Este conteúdo tem finalidade exclusivamente educativa e científica. Não substitui consulta médica, avaliação individualizada, decisão clínica à beira-leito ou protocolos institucionais locais.

Não devem ser publicados dados de pacientes, prontuários, exames identificáveis ou qualquer informação sensível.
